Moksh AI v3.0: An Agentic Hybrid Retrieval-Augmented Generation System with Explicit Query Routing and Dual-LLM Architecture

Proposes an explicit agentic retrieval decision layer that routes queries between vector memory, live web search, and a hybrid path, rather than retrieving blindly on every turn.
