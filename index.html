02 · Research

● Published · Zenodo 2026

Moksh AI v3.0: An Agentic Hybrid Retrieval-Augmented Generation System with Explicit Query Routing and Dual-LLM Architecture

Proposes an explicit agentic retrieval decision layer that routes queries between vector memory, live web search, and a hybrid path, rather than retrieving blindly on every turn. Pairs a local Llama 3 with a Gemini 2.0 Flash fallback that takes over when the local model isn't available, and it saves useful facts from conversations on its own.
